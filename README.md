# Superstore Sales Analysis

## Datheon Data Analytics & Power BI Internship

### 1. Project Overview
This project focuses on analyzing Superstore Sales data to identify business trends, evaluate sales performance, and generate actionable business insights using Microsoft Excel 365.

### 2. Project Objectives
- Analyze customer purchase volume.
- Identify monthly sales trends and seasonality.
- Evaluate revenue by product category.
- Compare sales and profit across regions and customer segments.
- Investigate the relationship between discounts and profitability.
- Develop at least five executive business findings.

### 3. Tools and Technologies
- Microsoft Excel 365
- Power Query
- PivotTables
- Excel Formulas
- Charts and Data Visualization

### 4. Project Structure
- `data/` – Original Superstore dataset.
- `excel/` – Cleaned data, analysis and dashboard.
- `screenshots/` – Dashboard and analysis screenshots.
- `power-query/` – Data cleaning transformation code.
- `README.md` – Project documentation.

### 5. Data Analysis Process
1. Import the Superstore Sales dataset.
2. Clean and transform the data using Power Query.
3. Analyze monthly sales performance.
4. Evaluate category-wise revenue and profit.
5. Analyze regional and customer segment performance.
6. Investigate discount sensitivity.
7. Create an interactive Excel dashboard.
8. Document five executive business findings.

### 6. Expected Deliverables
- Cleaned sales dataset.
- Excel analysis workbook.
- PivotTables and visualizations.
- Interactive dashboard.
- Five executive business findings.

### 7. Conclusion
This project demonstrates how Microsoft Excel can be used to transform raw sales data into meaningful business insights that support data-driven decision-making.****
